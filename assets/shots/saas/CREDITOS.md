# Créditos de las fotos de producto (capturas de Gondofy)

Las capturas de `assets/shots/saas/` muestran «Núcleo PC», una tienda ficticia creada para el portafolio.
Las fotos de producto vienen de Wikimedia Commons, con licencias que permiten el uso comercial.
La aplicación las recortó y convirtió a WebP, y aparecen reducidas dentro de capturas de pantalla.
Varias son de un modelo parecido, no del exacto: la columna «Foto» dice cuál es.
